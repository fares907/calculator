## ▶️ إزاي تشوف الشغل

### الطريقة الأفضل (وبتشتغل 100%)

افتح PowerShell في الفولدر ده وشغّل:

```bash
node serve.js
```

وبعدين افتح المتصفح على `http://localhost:8123`

**ليه الطريقة دي أحسن؟** لما تفتح الملف بالدبل-كليك المتصفح بيقفل IndexedDB لأسباب أمنية،
فالنظام بيرجع لـ localStorage الاحتياطي (اللي بيقع عند ~10 آلاف سجل).
مع الخادم المحلي بيشتغل بكامل قوته. ولما ترفعه على GitHub Pages هيشتغل بكامل قوته كمان.

### تشوفه على الموبايل والآيباد

وانت شغّال الخادم، هات عنوان IP الجهاز:

```bash
ipconfig
```

خد الرقم اللي جنب `IPv4 Address` (شكله كده `192.168.1.x`)، وافتح من الموبايل — بشرط
يكون على نفس شبكة الواي فاي:

```
http://192.168.1.x:8123
```

## 🚀 مشكلة الـ 15,000 سجل — الحل والنتايج

### اللي كان بيحصل قبل كده

- **`localStorage` سقفه 5 ميجا.** النسخة الاحتياطية لـ 15,000 سجل حجمها **3.6 ميجا** فعلياً — كنت هتصطدم بالسقف وتفقد البيانات.
- `renderLog()` كانت بتبني **الـ 15,000 صف كلهم** من الأول بعد كل حركة.
- `saveState()` كانت بتشتغل **مع كل حرف** بتكتبه في خانة السعر، وتعمل serialize للسجل كله.

### اللي بقى دلوقتي

الحل: **IndexedDB** + عرض صفحة صفحة + الرصيد متخزن لوحده مش بيتحسب من السجل.

### نتايج الاختبار الفعلي (اختبرته بـ 15,000 سجل حقيقي)

| العملية | الوقت |
|---|---|
| فتح الصفحة الأولى | **76 مللي ثانية** |
| القفز للصفحة 300 (نص السجل) | **96 مللي ثانية** |
| آخر صفحة (600) | **131 مللي ثانية** |
| بحث بالنص في الـ 15,000 | **175 مللي ثانية** |
| فلترة بالمادة + النوع | **160 مللي ثانية** |
| قراءة الرصيد | **أقل من مللي ثانية** |
| إعادة حساب الرصيد من كل السجل | **110 مللي ثانية** |
| تسجيل حركة جديدة | **~10 مللي ثانية** |
| تصدير Excel لكل السجل | ثانية تقريباً (1.36 ميجا) |

وأهم رقم: الصفحة فيها **677 عنصر HTML بس** رغم إن السجل فيه 15,000 حركة —
لأن العرض 25 حركة في المرة. يعني السرعة واحدة سواء عندك 100 سجل أو 100,000.


## ☁️ المزامنة بين الجهازين

عشان لما حد يسجّل حركة، الشريك يلاقيها عنده.

### الخطوة 1 — تعمل قاعدة البيانات (مرة واحدة بس)

**دي محتاجة إيدك انت — أنا مش بعمل حسابات نيابة عن حد.**

1. روح على **supabase.com** واعمل حساب مجاني.
2. اضغط **New Project** — اختار اسم وباسورد لقاعدة البيانات، والمنطقة خليها **Frankfurt** (أقرب حاجة لمصر).
3. استنى دقيقتين لحد ما المشروع يجهز.
4. من القائمة الجنب اختار **SQL Editor** → **New query**.
5. افتح ملف `supabase-setup.sql` اللي جنب الموقع، انسخه كله والصقه، واضغط **Run**.
6. روح **Settings → API** وخد منها حاجتين:
   - **Project URL** (شكله `https://xxxxx.supabase.co`)
   - **anon public** key (نص طويل بيبدأ بـ `eyJ`)

### الخطوة 2 — تفعّل المزامنة على الجهاز الأول

المخزن → **⚙️ الإعدادات** → **إعداد جديد من الصفر** → الصق العنوان والمفتاح → **تفعيل المزامنة**.

### الخطوة 3 — تربط الجهاز التاني

بعد ما تفعّلها على الأول، هيظهر لك **"رمز الربط"**.
انسخه وابعته للشريك (واتساب أو أي حاجة).

هو يفتح الموقع → **⚙️ الإعدادات** → يلزق الرمز في خانة **"عندك رمز ربط من الشريك؟"** → **ربط الجهاز**.

خلاص. من دلوقتي أي حركة يسجلها أي حد، التاني بيشوفها خلال **8 ثواني**.

### حاجات مهمة تعرفها

- **الشغل بيكمل من غير نت.** الحركات بتتسجل عادي وبتترفع لوحدها أول ما النت يرجع.
- **رمز الربط ده مفتاح البيانات.** أي حد معاه يقدر يشوف السجل كله. متبعتوش لحد بره الشركة.
- اللينك لوحده من غير الرمز **مبيوصّلش لأي بيانات** — أي حد يفتح الموقع من غير ربط هيلاقي مخزن فاضي على جهازه.
- الخطة المجانية في Supabase بتديك **500 ميجا** — يعني تقريباً **مليونين حركة**. مش هتحتاج تدفع.

## 📄 تقرير PDF

زرار **📄 تحميل تقرير PDF** فوق الرسم البياني.

بيطلّع تقرير **ملوّن ومصمم** فيه:
- ترويسة بالفترة والتاريخ
- الرصيد الحالي وقيمته بالفلوس
- كروت الملخص بالألوان
- الرسم البياني
- جدول الحركات بالتفصيل — بشارات ملوّنة للصرف والاستلام

**التقرير بيتبع الفترة والمادة المختارين في الرسم.** يعني تختار "آخر سنة" و"حديد" → التقرير يطلع كده.

### إزاي تحفظه PDF

لما تدوس الزرار هتفتح نافذة الطباعة → من خانة **الطابعة** اختار **"حفظ كـ PDF"** (أو **Save as PDF** / **Microsoft Print to PDF**) → **حفظ**.

على الآيفون والآيباد: بيفتح معاينة الطباعة → اضغط زرار المشاركة → **حفظ في الملفات**.

> **ليه بالطريقة دي؟** ده اللي بيخلي **العربي يطلع مظبوط 100%**. مكتبات الـ PDF الجاهزة بتكسّر الحروف العربية وبتفصلها عن بعض. الطريقة دي بتستخدم محرك الخطوط بتاع المتصفح نفسه، فالنتيجة نضيفة وملوّنة.

**ملاحظة:** لو الفترة فيها أكتر من 800 حركة، الجدول بيعرض أحدث 800 عشان الملف ما يبقاش مئات الصفحات — **بس الملخص والرسم البياني محسوبين على كل الحركات**، والتقرير بيقول لك كده بوضوح.

## ⚙️ الإعدادات — إيه الفرق بين الثلاثة؟

ناس كتير بتلخبط بينهم، فخليني أفصّلهم:

### 1️⃣ نسخة احتياطية / استرجاع — **أمان ضد الضياع**

| | |
|---|---|
| **بتعمل إيه؟** | بتنزّل **ملف** على جهازك فيه كل حركاتك وأسعارك ورصيدك |
| **إمتى تستخدمها؟** | كل أسبوع — تحفظ الملف على جوجل درايف أو الواتساب |
| **الاسترجاع؟** | لو الموبايل ضاع أو المتصفح اتمسح، تحمّل الملف تاني وكل حاجة ترجع |
| **بتشتغل من غير نت؟** | ✅ أيوه |
| **بتربط الأجهزة ببعض؟** | ❌ لأ خالص |

**الاسترجاع بيدمج مش بيمسح** — لو عندك 100 حركة واسترجعت ملف فيه 500، هيبقى عندك الاتنين مع بعض. والمكرر بيتحدّث مش بيتكرر.

### 2️⃣ المزامنة بين الأجهزة — **الشريك يشوف نفس الأرقام**

| | |
|---|---|
| **بتعمل إيه؟** | تربط جهازك بجهاز شريكك عن طريق قاعدة بيانات على النت |
| **إمتى تستخدمها؟** | لما تكونوا اتنين بتسجلوا حركات وعايزين تشوفوا نفس الرصيد |
| **بتشتغل إزاي؟** | كل حركة بتترفع لوحدها، وكل 8 ثواني بينزّل اللي عمله الشريك |
| **بتشتغل من غير نت؟** | ✅ الشغل بيكمل عادي، وبيتزامن لوحده أول ما النت يرجع |
| **محتاجة إعداد؟** | ✅ حساب Supabase مجاني (مرة واحدة بس) |

### 3️⃣ الخلاصة

> **المزامنة** = الشريك يشوف شغلك **دلوقتي**.
> **النسخة الاحتياطية** = شغلك ميضيعش **لو حصل مصيبة**.

**محتاج الاتنين.** المزامنة مش بديل عن النسخة الاحتياطية — لو حد مسح حركات بالغلط، المسح ده بيتزامن كمان ويروح عند الشريك! النسخة الاحتياطية هي اللي بترجّعها.

## ✨ اللي جديد في المخزن

- **جهة الصرف / المورد** و**رقم الإذن أو الفاتورة** مع كل حركة
- **معاينة قبل التسجيل**: بتشوف القيمة والرصيد بعد العملية قبل ما تضغط
- **بحث وفلترة** بالنص والمادة والنوع والتاريخ

- **سعة المخزن** بتظهر كنسبة مئوية
- **سعر لحظة الحركة متخزن مع كل سجل** — يعني لو غيّرت الأسعار بكرة، الحركات القديمة بتفضل بسعرها الصح
- **رسم بياني** لحركة المخزون: شهر / 6 شهور / سنة / سنتين
- **تقرير PDF ملوّن** بالرصيد والملخص والرسم وجدول الحركات
- **تصدير Excel** (في الإعدادات) بيحترم الفلاتر اللي مفعّلة
- **إعادة حساب الرصيد** من السجل لو حسّيت إن فيه حاجة مش مظبوطة
- في الحاسبة: زرار **📦 جيب من المخزن** بيجيب الأسعار والرصيد الفعلي على طول
