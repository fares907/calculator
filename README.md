# نظام مواد البناء — الإصدار 2

حاسبة أسعار + مخزن حديد وأسمنت. بيشتغل من غير نت، وبيتزامن بين الأجهزة.

---

## 📁 الملفات

```
calculator/
├── index.html              الصفحة الرئيسية
├── calculator.html         الحاسبة (حساب لحظي وانت بتكتب)
├── warehouse.html          المخزن
├── sw.js                   تشغيل من غير نت (Service Worker)
├── manifest.webmanifest    عشان يتحط على الشاشة الرئيسية كتطبيق
├── supabase-setup.sql      تجهيز قاعدة بيانات المزامنة (الإصدار 2 — مؤمّن)
├── serve.js                خادم معاينة محلي (مش جزء من الموقع)
└── assets/
    ├── css/app.css         نظام التصميم كله (فاتح + غامق)
    └── js/
        ├── core.js         أدوات مشتركة، الثيم، التنبيهات، النوافذ
        ├── icons.js        الأيقونات
        ├── store.js        التخزين — IndexedDB (الإصدار 2)
        ├── sync.js         المزامنة المؤمّنة
        ├── report.js       الرسوم البيانية وتقرير PDF
        ├── warehouse.js    منطق المخزن
        └── calculator.js   منطق الحاسبة
```

**مفيش ولا مكتبة خارجية.** كل حاجة مكتوبة بـ HTML/CSS/JS حديث (View Transitions،
‏`<dialog>`، ‏`@starting-style`، ‏OKLCH، ‏Container Queries، ‏Scroll-driven animations).
ده معناه: مفيش ثغرات مكتبات تتابعها، ومفيش حاجة تقيلة تتحمّل، والموقع سريع جداً.

## ✨ الجديد في المخزن

| | |
|---|---|
| **5 شاشات** | اللوحة · حركة جديدة · السجل · الأصناف · التقارير والجهات |
| **الأصناف** | حديد 8 / 10 / 12 / 16 / 18 / 22 / 25 / 32 مم، أسمنت عادي / مقاوم — وتقدر تضيف أي صنف. كل صنف له رصيد وحد تنبيه |
| **تعديل الحركة** | مش بس إلغاء — تعدّل الكمية أو السعر أو الجهة أو التاريخ، والرصيد بيتظبط لوحده |
| **زرار "تراجع"** | بعد أي تسجيل أو تعديل أو إلغاء بيظهر زرار تراجع لمدة 6 ثواني |
| **دفتر الجهات** | كل عميل ومورد وإجمالي تعاملاته — اضغط عليه تشوف حركاته وتطلع **كشف حساب PDF** |
| **تاريخ الحركة** | تقدر تسجل حركة بتاريخ قديم (اللي نسيتها امبارح مثلاً) |
| **سعر الحركة** | بياخد سعر السوق لوحده، وتقدر تغيّره للحركة دي بس |
| **اللوحة** | قيمة المخزون، حلقات السعة، حركة آخر 30 يوم، آخر الحركات، رسم بياني |
| **السجل** | بحث وفلترة بالمادة والنوع والصنف والجهة والتاريخ + تصدير Excel و PDF |
| **التقارير** | 5 فترات (شهر → سنتين) + الحركة حسب الصنف + تقرير PDF ملوّن |
| **فاتح وغامق** | زرار في كل صفحة، وبيفتكر اختيارك |
| **من غير نت** | بعد أول فتحة الموقع بيشتغل حتى لو النت مقطوع |
| **اختصارات** | <kbd>N</kbd> حركة جديدة · <kbd>/</kbd> بحث · <kbd>1</kbd>–<kbd>5</kbd> الشاشات · <kbd>Ctrl</kbd>+<kbd>Enter</kbd> تسجيل |

البيانات القديمة بتتنقل لوحدها أول ما تفتح النسخة الجديدة — الحركات القديمة بتتحط
تحت صنف "حديد (بدون مقاس)" و"أسمنت (بدون نوع)"، والرصيد بيفضل زي ما هو بالظبط.

### السرعة (اختبار فعلي على 15,000 حركة)

| العملية | الوقت |
|---|---|
| فتح أول صفحة من السجل | **3 مللي ثانية** |
| القفز للصفحة 300 | **8 مللي ثانية** |
| فلترة بصنف معيّن | **25 مللي ثانية** |
| بحث بالنص في الكل | **~230 مللي ثانية** |
| تسجيل حركة جديدة | **2 مللي ثانية** |

جرّب بنفسك من الكونسول (F12):  `Store.seed(15000).then(() => location.reload())`

## 🔐 الأمان — اللي اتصلح

| المشكلة | الخطورة | الحل |
|---|---|---|
| سياسة Supabase كانت `using (true)` — **أي حد معاه المفتاح العام كان يقدر يقرا ويعدّل ويمسح بيانات كل الشركات اللي على نفس القاعدة** (المفتاح نفسه موجود جوه رمز الربط) | 🔴 حرجة | الجدول اتقفل تماماً. الوصول بقى عن طريق دالتين بس، كل واحدة محصورة في غرفة واحدة، ومستحيل غرفة تكتب فوق غرفة تانية |
| رقم الغرفة كان 80 بت | 🟠 | الغرف الجديدة 128 بت |
| حقن صيغ في Excel: لو حد كتب `=HYPERLINK(...)` في الملاحظة، Excel كان بينفذها | 🟠 | أي خانة بتبدأ بـ `= + - @` بيتحط قبلها `'` |
| ملف الاسترجاع كان بيتحط في القاعدة من غير فحص | 🟠 | كل سجل بيتنضف ويتفحص (النوع، المادة، الكمية، الأطوال) والتالف بيتجاهل |
| مفيش سياسة أمان للصفحة (CSP) | 🟡 | كل صفحة فيها CSP بتمنع أي سكربت غريب وبتسمح بالاتصال بـ Supabase بس |
| المعرّف كان بيتعمل غلط لما تفتح من عنوان الشبكة المحلية (`http://192.168…`) فالرفع للسحابة كان بيفشل | 🟡 | UUID صحيح في كل الحالات |
| المزامنة كانت ممكن تكتب نسخة قديمة فوق تعديل أحدث | 🟡 | الأحدث دايماً بيكسب — على الجهاز وعلى السيرفر |

## ☁️ المزامنة — لازم تعمل الخطوة دي (حتى لو كانت شغالة قبل كده)

1. افتح مشروعك على **supabase.com** → **SQL Editor** → **New query**.
2. الصق ملف **`supabase-setup.sql`** الجديد كله واضغط **Run**.
   (آمن على قاعدة موجودة — مش بيمسح أي حركة، بيقفل الثغرة بس.)
3. خلاص. الأجهزة المربوطة بتكمل بنفس رمز الربط.

> ⚠️ لحد ما تشغّل الملف الجديد، المزامنة هتقول: "قاعدة البيانات محتاجة تحديث".
> ده مقصود — النسخة الجديدة رافضة تشتغل على القاعدة المفتوحة.

**أول مرة خالص؟** اعمل حساب مجاني على supabase.com → New Project (المنطقة Frankfurt) →
شغّل الملف → من **Settings → API** خد الـ Project URL والـ anon key →
في المخزن: ⚙️ الإعدادات → إعداد جديد من الصفر → الصقهم → تفعيل.
بعدها انسخ **رمز الربط** وابعته للشريك.

- **رمز الربط = مفتاح البيانات.** متبعتوش لحد بره الشركة.
- المزامنة مش بديل عن **النسخة الاحتياطية** — اعمل نسخة كل أسبوع (⚙️ → نسخة احتياطية).
